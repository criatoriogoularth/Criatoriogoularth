Como funciona
• O backup é um arquivo único (.json). Guarde uma cópia fora do computador (e-mail, nuvem, pen drive).
• Restaurar APAGA os dados atuais e coloca no lugar o que está no arquivo. Baixe um backup antes de restaurar.
• O arquivo não leva senhas. Serve também para mudar de servidor ou de plano sem perder nada.
• Baixar o backup continua funcionando mesmo se o seu plano vencer: os dados são seus.
